# Reconstruir para Android — v0.13.0

Aplicativo Android do Reconstruir, pensado para funcionar localmente no aparelho.

Incluído:
- onboarding
- check-in de energia, estresse, sono e humor
- fases da reconstrução
- 3 prioridades do dia
- tarefas e conclusão
- hábitos
- reflexão e revisão semanal
- evolução
- Reconstruir IA em modo local/demonstração
- persistência no aparelho com SharedPreferences

Build automático:
- GitHub Actions
- JDK 17
- Gradle 9.1.0
- Android Gradle Plugin 9.0.1

APK debug gerado em:
app/build/outputs/apk/debug/app-debug.apk

Identidade:
Reconstruir
“Um passo de cada vez. Uma vida de cada vez.”
Package: com.reconstruir.app
